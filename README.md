# Monuments

Planning package for the monument sign website. Nothing here is the site itself yet.

- `SPEC.md`: the full build specification (design direction, page architecture, final copy, builder, payments, Cloudflare setup, checks).
- `KICKOFF-PROMPT.md`: the short prompt to paste into a new Claude Code session to start the build.
- `design/`: a reference comp of the hero and the size lineup, with screenshots and the two open-license typefaces.
